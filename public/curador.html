    Como publicar

    1. Baixe o arquivo atualizado e substitua public/pontos-fixos.json no seu projeto. Não edite o arquivo gerado em dist.
    2. Revise os pontos de exemplo. Reabra esta ferramenta com a base atualizada antes de cadastrar outro ponto.
    3. Na raiz do projeto, teste e envie usando os comandos abaixo.
    npm test
npm run build
git add public/pontos-fixos.json
git commit -m "feat: atualiza pontos fixos do mapa"
git push

    Com o repositório conectado à Vercel e deploy automático ativo, ela republica sozinha após o push. Só então os pontos aparecem para todos. O download não publica nada.
